# 刊登召募實況展示

使用者已於對話確認開始：左側招募需求，右側沿用虛擬瀏覽器外框的自建招募平台，展示 Agent 填寫、預覽與使用者確認後的模擬發布。

採前端本機展示，不呼叫 104、不提交外部資料，不假稱真實 AI 操作。畫面明示「模擬平台」與固定腳本；地址列使用 demo.local，不冒用正式網站。需求預帶目前企業情境，允許編輯。模擬職缺表單依序填寫，完成後停在預覽；必須另按確認才顯示發布結果。重做、退出或切換功能停止計時器，編輯後舊預覽失效。發布成果只保留當前頁面。

## Approaches
- 僅空白實況外框：快速但不能展示操作。
- 自建 DOM 表單與模擬游標（採用）：可驗證流程，後續可用後端事件替代固定步驟。
- 真網站 iframe／自動發布：目前沒有服務或授權，不適用。

保留地圖背景、上方入口亮暗切換及既有校園／獵頭功能。這次不做履歷、邀請、真實發布或模型串接。

## 第二版（對話已確認開始）
三幕互動：一句話需求與可編輯職稱／人數卡片 → 動態補齊／虛擬瀏覽器 → 單次人工審核並模擬刊登。初始只需職稱、人數；公司與地點帶入企業情境。未知薪資留待確認，不以網路行情替企業承諾。來源標籤區分使用者、企業情境、範本草稿及待確認；網路來源尚未串接，必須標示未連線。可暫停／繼續、略過動畫看草稿、退回修改，退出取消所有計時器。審核內容直接編輯，缺必要資料不可刊登；唯一確認按鈕為「審核通過並模擬刊登」。本次只做前端渲染／事件介面，不使用真模型、搜尋或 Computer Use。新增動態階段列、來源節點連線、欄位逐字填寫與完成卡。
