| 部署、成本及實測限制 | 說清本機完成程度、網路依賴與正式部署缺口 |

## C 我們的串接流程

```flow LR
位置與科系 -> 校區搜尋API: GET 查詢
校區搜尋API -> 搜尋結果: 匹配科系與總機
搜尋結果 -> 前端面板: 點選校區
前端面板 -> 原視角: 返回
```

面板使用搜尋結果中的直接匹配與相關科系。
相同科系依 ID 去重，並保留授課校區待核驗提示。
補充科系另顯示「名冊未列，招生狀態待查」。
舊統計接口、人數資料表及企業證據檔已移除。

校園查詢使用一般 GET 與 JSON。
不需照搬找人 Agent 的任務串流、模型設定或費用估算。
重新搜尋時由前端取消舊請求，並忽略過期回應。
