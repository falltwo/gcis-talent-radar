# 校園人才媒合前端展示

此版用來驗證操作，不代表真實校園推薦或合作承諾。

- 點選「校園人才媒合」後，其他兩個入口變淡但仍可點選；再次點選或按「退出媒合」回復三個入口正常狀態。
- 地圖由企業道路選點向虛構校區連線；點選校區或左側清單可開啟學校浮窗。
- 可調整職務關鍵字與半徑、加入或移除合作候選，並切換資料助理。
- 換探索位置後重新生成展示座標並清空候選。候選只存在當前頁面記憶體，重新整理不保留。
- 其餘兩個功能目前僅顯示準備中提示。

## 展示資料

`ui/static/campus-demo.json` 有三個虛構校區。經緯度以企業選點加上東／北公里偏移計算；距離為這些虛構座標的球面直線距離，不是通勤距離。校系與職務僅是展示關聯，沒有模型推薦分數。畢業生人數、學年、官方窗口留空並顯示待接正式資料。

## 後續後端銜接

正式資料應提供穩定的校區 ID、學校／校區名稱、經緯度、相關校系、職務關聯理由與出處、資料年度、官方窗口 URL，以及畢業生統計的口徑與年度（不可取得則為 null）。前端需以實際經緯度替換 offset_km 展示轉換，改讀正式查詢 API，並按資料覆蓋範圍呈現無資料狀態。正式上線前不可只移除展示標籤，仍保留相對生成的座標。

地圖連線是探索候選的互動效果，不代表校方已同意合作；加入候選沒有寄信或聯絡行為。

### 連線端點修正

學校與企業 DOM 標記原本以 position:relative 覆蓋 MapLibre 標記的絕對定位，導致標記受前方元素排版影響而偏移。已改回 position:absolute，保留 MapLibre 的座標轉換。瀏覽器檢查企業及三個校區圖示中心與其地圖投影位置：修正後皆為 [0, 0] 像素偏移；縮放與旋轉後重查結果相同。

搜尋範圍改為數值輸入，預設 15 公里，最小 0.1 公里，允許任意小數；空白、非數值、零或負數不能提交。沒有額外設定公里上限，展示校區仍只有原有三筆。
