# 刊登召募虛擬瀏覽器展示

選擇上方「刊登召募」進入雙欄工作台：左側需求可編輯，右側顯示自建人才招募網站。固定腳本依序填寫公司、職缺、地點、薪資、人數及技能，完成後停在預覽，只有使用者另按「確認並模擬發布」才顯示成功。這不是 AI 模型、真實 Computer Use、104 串接或對外刊登，地址列使用 demo.local。

企業名稱、主要職務、工作地點及增聘人數來自目前企業情境；月薪預設 35000–45000 是可編輯的展示輸入，不是官方薪資或建議開薪。招募需求只保留於目前頁面，不上傳、寄信或呼叫外站。

「返回修改」清除舊預覽，「建立另一份」重新開始。退出、再次點入口或切換校園／獵頭模式會取消計時器、清除預覽並恢復原側欄狀態。右側欄位用 textContent 顯示輸入。

後續可將固定腳本替換為後端進度事件：每個欄位填寫、產生預覽、等待 HR 確認、模擬發布結果；仍應保留人工確認關卡及清楚的示範標示。

## 第二版：三幕互動

初始輸入職稱、人數，或使用一句話加「帶入需求卡片」。一句話解析為本機簡易規則示意，允許人工修正，未使用語言模型。公司與地點沿用企業情境，薪資不預填。其他工作內容由明示的本機通用範本產生。

第二幕顯示來源節點、逐字填表與游標，支援暫停／繼續、直接看草稿。來源分使用者、企業情境、範本、待確認與人工修改。網路節點明示「尚未串接・未搜尋」。第三幕提供可編輯欄位；月薪上下限必須補齊且有效，按「審核通過並模擬刊登」一次就完成，沒有第二次確認。退回修改保留已改內容與薪資。

## 第四版：地圖懸浮試作

`recruitment-map.css` 單獨處理新版版面：初始地圖上左側需求、右側瀏覽器，中間保留地圖與選點；提交後以 Web Animations FLIP 從原右側框移到地圖中央，放大並回彈（950ms）。審核維持相同置中幾何，不重播入場。輕暗遮罩只在執行／審核／成果階段顯示。左上任務卡可展開詳情；欄位來源另能在中央顯示說明。

完成後「收回地圖」回復左右面板，在原任務選點旁顯示「已模擬刊登 N 個職缺」。筆數僅在目前頁面記憶體內，依任務開始時的地圖座標記錄；不跨頁保留，不代表外站刊登。動態減少偏好下直接切換版面。退出或切換功能會取消入場動畫及工作計時器。

本版驗證：Node 9/9、JS 語法／資產引用及差異空白檢查通過。瀏覽器量測初始右側視窗寬 500、置中後寬 860；相對地圖中心偏差 [0,0]，遮罩透明度 0.28。單次審核完成後收回地圖回到 brief，標記顯示 1 個模擬職缺。獨立只讀審查未發現重要缺陷。此版無後端改動，未重新執行 Python 全套測試。

### PR #31：薪資萬位與職缺歸屬修正

- 月薪可使用 `4萬到6萬`、`四萬到六萬`、`4萬到六萬`、`4.5萬至6.5萬`、`4到6萬`、`40,000至60,000` 或 `十萬元`；解析後統一為整數元。薪資單位仍為月薪，不會自行推估市場行情。
- 支援先列出職缺與人數，再按職稱指定薪資，例如 `1位工程師、1位經理，工程師月薪50000、經理月薪100000`。具名薪資只套用該職缺；單獨寫月薪且前方沒有其他職稱時，對應緊接在前的職缺。
- 不完整範圍、未知職稱的薪資、同名職缺無法區分或互相衝突的薪資指定會顯示說明，不建立部分草稿、不以數字前綴代替整段金額。可以修正訊息後重新送出，退回時保留的人工草稿不會被錯誤訊息清掉。
- 阿拉伯數字的人數千分位與逗號分隔職缺保持可用；例如 `3位工程師月薪50000至60000,5位助理月薪35,000`。
- 新增 `tests/frontend/recruitment-salary-regressions.test.cjs`，涵蓋薪資格式、職稱歸屬、整批核准至紀錄、錯誤輸入與再次送出；GitHub Actions 同時執行前端回歸測試。
