# 刊登召募虛擬瀏覽器展示

選擇上方「刊登召募」進入雙欄工作台：左側需求可編輯，右側顯示自建人才招募網站。固定腳本依序填寫公司、職缺、地點、薪資、人數及技能，完成後停在預覽，只有使用者另按「確認並模擬發布」才顯示成功。這不是 AI 模型、真實 Computer Use、104 串接或對外刊登，地址列使用 demo.local。

企業名稱、主要職務、工作地點及增聘人數來自目前企業情境；月薪預設 35000–45000 是可編輯的展示輸入，不是官方薪資或建議開薪。招募需求只保留於目前頁面，不上傳、寄信或呼叫外站。

「返回修改」清除舊預覽，「建立另一份」重新開始。退出、再次點入口或切換校園／獵頭模式會取消計時器、清除預覽並恢復原側欄狀態。右側欄位用 textContent 顯示輸入。

後續可將固定腳本替換為後端進度事件：每個欄位填寫、產生預覽、等待 HR 確認、模擬發布結果；仍應保留人工確認關卡及清楚的示範標示。

## 第二版：三幕互動

初始輸入職稱、人數，或使用一句話加「帶入需求卡片」。一句話解析為本機簡易規則示意，允許人工修正，未使用語言模型。公司與地點沿用企業情境，薪資不預填。其他工作內容由明示的本機通用範本產生。

第二幕顯示來源節點、逐字填表與游標，支援暫停／繼續、直接看草稿。來源分使用者、企業情境、範本、待確認與人工修改。網路節點明示「尚未串接・未搜尋」。第三幕提供可編輯欄位；月薪上下限必須補齊且有效，按「審核通過並模擬刊登」一次就完成，沒有第二次確認。退回修改保留已改內容與薪資。

後續後端可提供任務進度、欄位值與來源資料，再替換目前的固定事件排程；前端動畫只應反映收到的進度，不能把本機範本宣稱為真實搜尋或 Computer Use。

驗證：`node --test tests/frontend/recruitment-flow.test.cjs` 8 passed；原版控 Python 測試 516 passed（依前述指令忽略本機未追蹤的舊影片測試）。瀏覽器驗證了：5 人 CNC 需求拆解、暫停／繼續、直接看草稿、缺薪資阻止刊登、修改後來源標籤說明同步、退回保留品管職稱與 38000–45000 月薪、最後只按一次完成刊登。獨立審查提出的退回丟失輸入及來源說明矛盾已重現並修正。
