# 02 資料集清單

> 組員找到資料集就照下面的格式加一節，交回來後統一驗證（實際打 API 或下載檔案）。
> 商工登記的 GCIS 資料已經整理在「已確認」區，不用重找。

## 目前最缺

1. **製造業職缺**：優先用台灣就業通的開放資料。要能切台中、切職類，最好有歷史資料。
2. **台中在地數字**：工業區廠商家數、製造業勞保投保人數、台中市政府或公會的缺工調查。
3. **科系供給**：教育部各系所畢業生人數，要能對到製造業相關科系（機械、電機、化工、材料等）。

## 取得方式的原則

- 政府開放資料平台、機關官網：可以用，寫清楚出處。
- 政府網站沒有 API、只能爬：可以用，記下網址和抓取日期。
- 商業平台（104、1111 等）：不當主力。要用的話只抓小樣本、只用統計後的數字、不公開原始資料，並在文件寫明限制。
- 有個資（姓名、電話、Email）的欄位不要存。

## 填寫範本

複製這一段往下貼：

```
### 資料集名稱（照官方原名）

- 網址：
- 提供機關：
- 更新頻率：（每月／每季／每年／不定期）
- 時間範圍：（例：2015-01 起）
- 能不能切到：台中 □ 行政區 □ 產業 □ 職類 □
- 取得方式：API ／ 檔案下載（CSV、XLSX、ODS…）／ 只能爬網頁
- 授權：（政府資料開放授權條款第 1 版／其他／不明）
- 主要欄位：
- 要拿來算什麼：
- 找的人：
- 驗證結果：（Hermes 填）
```
