# 行政區徵才比較

選擇 2～3 個台中行政區，依工作領域、職稱或職類關鍵字，比較同一份台灣就業通官方快照。

## 使用方式

1. 執行 `python server.py`，開啟畫面上的本機網址。
2. 點選首頁的「行政區徵才比較」，或直接開啟 `/legacy#compare`。
3. 預設比較大雅區、潭子區、神岡區的智慧製造與精密機械相關職缺。
4. 調整地區與工作條件後，按「開始比較」。第三個行政區可選擇「不加入第三區」。
5. 展開行政區，查看主要職類及最多 10 筆來源職缺；「資料來源與計算方式」附快照日期、擷取時間與官方來源。

## 指標

| 指標 | 計算方式 |
|---|---|
| 刊登職缺 | 篩選後的職缺紀錄筆數 |
| 刊登需求人數 | 篩選後 `openings` 加總 |
| 徵才公司 | 篩選後非空白公司名稱去重；不是統編核實的企業總數 |
| 主要職類 | 優先採用職類細類名稱，依刊登數與需求人數排序，顯示前五類 |

工作領域採用既有版本化職務文字規則，關鍵字再與此篩選取交集。這不是公司的正式行業分類。

資料是公開職缺樣本，不是全部雇主或實際缺工數；不產生缺工率或選址評分。職缺目前是否開放，以來源頁為準。頁面會自動讀取已匯入資料中的最新快照，並顯示資料日期。

比較頁沿用 `/legacy` 的介面外殼，但這個分頁只讀官方職缺與抓取稽核表；不使用其他舊分頁的模擬指標。

## API

`GET /api/official/district-comparison`

Query 參數：

- `districts`：重複傳入 2～3 個不同的台中行政區。
- `industry_id`：選填，例如 `IND_MFG`；不傳則涵蓋全部工作領域。
- `occupation_keyword`：選填，前後空白會去除，上限 60 字。

例如：`/api/official/district-comparison?districts=大雅區&districts=潭子區&industry_id=IND_MFG&occupation_keyword=CNC`

回傳 `snapshot_date`、套用條件、各區 `comparisons` 與 `evidence`。使用單一 SQLite 讀交易，確保快照、職缺與抓取稽核一致。

- 無符合刊登且稽核完整：成功回傳 0。
- 單區達來源查詢上限：保留結果並標示 `QUERY_LIMIT_REACHED`，只能當觀測下限。
- 缺少或不一致的行政區稽核：回傳 503，不以 0 或舊快照補位。
- 行政區重複、數量不符、不支援產業或關鍵字過長：回傳 400。

## 驗證

`python -B -m unittest tests.test_district_comparison -v`

13 項測試使用獨立暫存 SQLite，涵蓋聚合、雇主去重、篩選交集、快照一致性、空結果、查詢上限、稽核不完整與 API 參數解析，不修改專案原始資料庫。

前端採本機靜態 JavaScript/CSS，不新增套件、付費 AI 或外部資料服務。既有前端圖表套件不可用時，不影響比較頁。
