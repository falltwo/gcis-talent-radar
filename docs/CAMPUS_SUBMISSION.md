# 校園後端 PR 提交範圍

準備分支：`codex/campus-backend-pr`，由 `main` 的 `595f2e2` 建立。沒有包含舊校園整合分支的 commit 歷史，原整合版保留。本分支供後端交付 PR 審查，正式前端仍保留 main 原樣。

## 正式後端內容

- 五個教育 GET API、查詢／簡稱／詳情／總機邏輯。
- 當前發布版本教育 SQLite、兩份 schema、三份搜尋與座標參考資料。
- 三支教育 ETL、兩份依賴清單、五支後端測試與交付驗證工具。
- 主程式的教育路由 import／註冊、CI 依賴安裝、教育備份忽略規則及前端參考檔 LF 換行規則。
- [接口草案](CAMPUS_API.md)、[啟動說明](CAMPUS_BACKEND_SETUP.md)、來源說明與 [驗證摘要](CAMPUS_PR_VALIDATION.md)。

不保留舊人數資料表、統計 API 或企業排行證據。科系名稱仍有補充來源；`registry_listed=0` 須提示名冊未列與招生狀態待查，不據此宣稱停招。

## 前端只作參考

`docs/frontend-reference/` 提供 patch、README 及檔案校驗清單。這是測試過的整合參考，沒有直接套到正式 `ui/`。

patch 包含鏡頭聚焦／返回、學校資訊、匹配科系、公開總機及來源。電話不提供超連結，畫面不顯示查核日期、人數或企業熱門；補充科系會標示「名冊未列，招生狀態待查」。

團隊可閱讀、手動整合或另開分支套用，詳見 [參考版操作](frontend-reference/README.zh-TW.md)。下載或解壓縮本身不會修改前端。

## 不納入提交

`.env`、金鑰、密碼、token、Git／stash 歷史、稽核或使用者日誌、SQLite 備份、原產業 DB、原始學校網頁／CSV、截圖、舊計畫書、個人技能目錄、整套前端及本機 ZIP 包均不納入。

ZIP 只作外部交付的包裝，PR 應呈現實際後端檔案及必要的主程式／CI／忽略規則差異。包裝用的根目錄 MANIFEST、README 及後端 integration patch 不需重複放入本分支，因為後端修改已整合到實際檔案。

提交前請檢查實際差異及暫存清單，不能直接對原整合分支使用 `git add .` 或推送。提交範圍應以本分支的實際檔案清單為準。
