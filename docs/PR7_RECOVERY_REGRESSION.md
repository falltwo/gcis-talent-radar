# PR #7 缺月修復回歸驗證

驗證日期：2026-10-05（Asia/Taipei）。針對驗收 R1、R2、R3 修正。

- R1：主 ETL 以 `year_month + industry + metric` 核對官方月報重疊資料；先拒絕矛盾，再只將家數缺值的鍵交给填補函式。既有家數與資本額保持原值，新增觀測值標記 `official_monthly_recovered`。單筆、部分指標、整月缺值及完全無缺值都有直接呼叫 `transform()` 的回歸測試。
- R2：家數確認為有限、非負整數後採精確相等比較，不將小數轉整數。七月、十月、2014-11 控制資料及補回月份共用此規則。資本額獨立採 `rtol=0, atol=1e-5`。修復程式在所有衝突檢查完成前不寫 CSV、catalog 或報告；測試在暫存副本驗證各控制月份及補回月份相差 ±1 家必須拒絕，檔案保持不變。
- R3：舊測試改驗證 2025-08、09 製造業新設為 91、75 家及官方補回標記，保留 2026-08 的 75 家與 2010-12 孤立歷史月份檢查。
